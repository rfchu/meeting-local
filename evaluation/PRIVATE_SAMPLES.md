# F2：私有真实语音标注与评分

此流程与公开的自编 TTS 固定集分开。真实片段、来源定位、人工参考和评分均保存在当前工作空间的 `data/quality-samples/`（或配置的数据目录下同名目录），不进入 Git，不调用云端 ASR／LLM。目录沿用工作空间既有的存储／同步设置，本功能没有新增远端上传；如该目录已受系统云盘管理，仍遵循其设置。

## 标注流程

运行管理 → 运行环境 → 真实样本与人工标注：

1. 用户确认使用权限和真实语音来源，上传 1～120 秒、不超过 20 MB 的音频片段。服务只在本机转换为 16kHz 单声道 PCM；不请求网络媒体、不把长音频悄悄截短为样本。原文件名不保存，不自动读取其他会议。
2. 新片段始终是草稿，逐字参考为空；回听后手工填写参考并确认。不会用模型输出直接充当真值。该确认是单个用户的来源与回听声明，不代表双人独立标注或专家认证。
3. 每次保存产生不可变参考版本。版本检查拒绝迟到覆盖；勾选已确认样本后冻结固定集，绑定样本 ID、参考版本／指纹、音频 SHA256 及分类。未标注片段不得冻结，冻结时版本已变化也会拒绝。
4. 后续修改参考不改变旧固定集和评分；页面分别提示标注版本和评分口径是否仍匹配。实际音频变更会阻止回听核验／再次评分，不按新文件重解释历史结果。

原生短测、已有会议来源和手工标注是不同证据。若导入已选择会议的片段，私有来源记录包含会议版本、片段 ID 及音频范围，不据整场会议存在一个 manual 修订就认定全文已逐字校对。来源须在首次参考标注前固定，后续不能静默替换。

## 显式运行私有 ASR

页面不自动推理，不改变用户默认模型。冻结后从界面复制固定集 ID，空闲时运行：

```sh
.venv/bin/python scripts/evaluate_private_quality.py --dataset-id <固定集ID> --engine whisper --run-local-models
.venv/bin/python scripts/evaluate_private_quality.py --dataset-id <同一固定集ID> --engine qwen --run-local-models
```

可通过 `--data-root` 显式指定另一个已有私有库。缺少 `--run-local-models` 时不启动模型；库不存在时不创建或读取其他目录。与 F1 一样检查模型驻留和正式任务繁忙，顺序执行，环境禁用模型网络下载，不读取云端 LLM 配置。每条已提交请求最多运行 300 秒；正式任务在中途开始时，不提交下一条评测。

候选导入文件为 `{"outputs":{"<样本ID>":"实际转写"}}`，必须覆盖该固定集全部且仅包含其样本，失败样本不能从分母剔除：

```sh
.venv/bin/python scripts/evaluate_private_quality.py --dataset-id <固定集ID> --predictions /private/tmp/private-predictions.json
```

评分保存在同一个私有 SQLite 库；终端只打印不含原文的汇总，不导出实际录音、参考或候选原文。导入候选明确标记为未独立执行，不冒充本机模型实测。CER 沿用 F1 的文本归一化与字符编辑距离，保留数字书写差异；不评价事实真伪、语义覆盖、多说话人 DER 或时间对齐。

私有报告模式为 `private_real_speech_asr`，与公开 TTS 结果不混成一个总体分数，也不使用 F1 的公开固定集比较入口。先核对同一私有固定集和评分口径，再比较对应结果。结果保存和本机 CLI 使用维护共享租约；侧库与音轨纳入既有离线数据备份范围，不改变主库 v22。

## 本轮进度边界

Qwen 的 F1 同输入基线已补齐，四段自编 TTS 的归一化 CER 为 0%，Whisper 原基线为 4.918%。仅限该小型合成集，不能据此排名真实会议表现。

首批从用户指定会议提取两条真实片段，共约 33.4 秒，专名和数字场景。用户明确回复“两段正确”后保存参考，并冻结 1 个私有集，共 163 个归一化参考字符。标注方法记录为 `user_verified_existing_transcript`：既有转写经过用户回听确认，不声称独立盲写或双人标注。来源版本、范围、实际片段和原文仅留私有库，不写入此文档或 Git。

已按同一私有集顺序实测：Whisper 字面差异 3/163，严格 CER 1.840%；Qwen 字面差异 31/163，严格 CER 19.018%。本机事后诊断发现 Qwen 的数值中文写法与参考中的阿拉伯数字形式可解释这 31 处字面差异；该诊断只用于解释，不改正式分数、不生成新的“0%”真实评分，不把事后替换规则当作通用指标。首批样本很少且参考为辅助校对，不能据此排名模型或选择默认引擎。

后续优先设计带负例的数字等价指标版本，并与严格 CER 并列；扩展噪声、重叠、长句边界及独立复核。在线队列化评测、私有报告自动回归门槛、删除／撤销授权和双人复核属于后续工作，当前界面不提供自动发送或发布。
