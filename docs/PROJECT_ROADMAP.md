# 项目路线图

| 能力 | 当前状态 |
| --- | --- |
| 会议流程 | 录音、导入、转写、原音核对、内部及对外交付、跨会议跟进均已有可用流程。 |
| 会中工作台 | 实时文字、概览与简记共享同一个工作台，分别使用完整正文区域。概览与纪要可定位原话或回听。 |
| 原生伴随窗 | 默认显示录音状态，可切换双语或重点，并返回本场。内置屏和 Sidecar 扩展屏已完成放置与断开回屏验证。 |
| 语言支持 | 中文和英文用于常规流程。日语开放实验性会后原文和中文译文，可按音频块回听。 |
| 检索与问答 | 支持中英文关键词、基于已配置模型的语义检索和带原文引用的跨会议问答。日语实验草稿保留在本场。 |
| 本机交付 | 支持 Apple Silicon Mac 源码部署、原生宿主构建、备份恢复和本机升级回退。 |

当前验收关注真实录音中的工作台切换、悬浮窗返回本场和概览定位原话。Sidecar 结果不覆盖有线显示器，Lark 共享接收端验收暂缓。长录音、睡眠唤醒及实际设备争用仍需现场证据，发现具体问题后定向处理。见[硬件验收](engineering/HARDWARE_ACCEPTANCE.md)。

日语跨会议中文检索与原文引用仍待验证。现有样本出现姓氏和人数误识，原文时间戳精度为音频块。正式检索、引用和实时双语分别验收。见[日语样本与结果](../evaluation/baselines/ja-dominant-v1.json)。

当前范围、后续优先级和任务状态见[产品需求](specs/PRD-meeting-workflow.md)、[实施计划](planning/plan.md)及[任务清单](planning/todo.md)。已交付批次的技术背景和验证记录见[工程演进与历史验收](engineering/DELIVERY_HISTORY.md)。专项质量评测暂缓，已完成的基线及复现方式见[固定质量评测](evaluation/README.md)。
