## E6：独立采集控制服务与受控接管（已完成首版）

新原生录音默认由独立 broker 进程持有 build 3 采集器，API 作为有租约的控制者。API 正常退出释放控制权，崩溃不会关闭采集器 stdin；录音写盘与 API／ASR 生命周期分开。旧 stdin 录音保持原恢复边界，不做热升级。协议详见 [CAPTURE_PROTOCOL.md](engineering/CAPTURE_PROTOCOL.md)。
