# 中文会议记录

模块 `chinese-record`。P0。覆盖 PRD P0-03、04、11。依赖 `meeting-intake` 的有效片段及保存范围。见[共用规格](SPEC-workflow-common.md)。

用户在会中可切换原文与中文视图。中文片段直接显示原文，已确认的英文片段可异步生成中文译文。会后按同一来源时序供阅读、纪要和检索。原文仍是引文与回听依据。建议以片段及其内容版本、源语言、目标语言、模型配置绑定译文任务。相同输入的重试复用有效结果。

| ID | 操作与异常 | 验收 |
| --- | --- | --- |
| CR-01 | 使用中英混说样本，选择中文视图 | 中文保持原文，英文确认后可显示译文。原译都能定位同一音频时间范围 |
| CR-02 | 翻译失败、取消、缺少语言信息或模型不可用 | 原文仍可读与回听，待处理和失败范围可辨。可针对失败范围补译。未知语言保留原文并提示待确认 |
| CR-03 | 翻译运行时编辑、删除或替换原文 | 旧结果不会成为当前译文。受影响范围标记待补译，其余有效结果仍可用 |
| CR-04 | 会后读取只有部分译文的记录，或读取旧会议 | 可辨识哪些段落是原文、译文或缺译。整理前展示缺口，用户可补译或明确继续整理可用内容 |

复用 `app/languages.py`、`app/live_results.py`、现有模型配置和检查点。基线命令 `.venv/bin/python -m pytest tests/test_language_policy.py tests/test_live_session.py -q`。中英混说按实际片段能力验收，细粒度语言识别及模型选择留待计划评审验证。
