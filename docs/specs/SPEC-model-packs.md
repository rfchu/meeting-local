# 听记模型包规格

## 目标与范围

提供一份版本化完整包，覆盖独立版声明支持的本地模型能力。包内沿用现有 `models/` 相对路径和文件布局，应用通过一个模型根目录向各引擎提供路径。包不包含 LLM 权重、个人配置、会议数据、下载缓存及临时压缩包。

复用仓库中的 `models-manifest.json` 与 `qwen-models-manifest.json` 作为现有文件的清单来源。发行清单还应记录包版本、兼容的 App 版本、能力对应的必要文件、相对路径、字节数和 SHA-256。明确列出该发行版承诺支持的转写、对齐、发言人区分及其他本地模型能力，并核对对应模型的来源和发行条款。

## 导入流程与异常

- 「运行管理 → 模型」提供三个入口：指定 HTTPS URL 下载完整包、选择本地压缩包、选择已有模型目录。镜像和离线来源使用同一份可信发行清单。下载地址及每一跳重定向都必须是可公开访问、证书可验证的 HTTPS。下载先写入私有暂存区，再按与本地 ZIP 相同的规则解包和校验。中断或取消后清理部分文件，重试从头下载。
- 默认复制到 App 管理的模型根目录。展示预估空间、进度与当前阶段，下载或校验失败后可重试，取消不影响在用版本。目录导入检查云端占位文件，提示先下载到本机。
- 先在暂存目录校验清单和文件，再切换模型版本。拒绝越界路径、重复路径、符号链接及未声明的可执行内容。只安装清单许可的文件，任何路径都不能写出暂存或目标根目录。
- 录音、试录或识别任务正在使用当前模型时，允许准备新版本，延后切换。失败后保留旧版本，运行管理显示实际启用的版本和能力状态。

## 验收标准

| ID | 操作 | 通过条件 |
| --- | --- | --- |
| MP-01 | 分别从 URL、压缩包、现有目录导入同一完整包 | 结果路径、版本和文件哈希一致，承诺的引擎能力通过离线探测 |
| MP-02 | 断网、磁盘不足、取消，或提供缺失、损坏、版本不兼容的包 | 能区分失败原因并继续操作，旧模型仍可运行 |
| MP-03 | 导入路径越界或包含链接的包，以及只有云端占位文件的目录 | 拒绝不安全的内容，标出不可读文件，目标之外无写入 |
| MP-04 | 识别期间导入新版本，再结束当前任务 | 活动任务继续使用原版本，空闲后才切换 |
| MP-05 | 导入完成后断网，移动原导入目录并重开 App | 可识别测试音频，模型无需重新下载 |

测试用合成小包覆盖导入、损坏和回滚，完整发行包另做哈希核对和实际推理验证。本地导入支持 ZIP 和 ZIP64，包内沿用 `models/` 布局。发行 URL、首发完整包清单及大小待发行样包确认。
