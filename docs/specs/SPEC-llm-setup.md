# LLM 配置引导规格

## 目标与范围

LLM 由用户自行安装、运行和配置。听记提供本地和云端配置引导，复用「运行管理」现有模型配置、连接测试及功能默认项。用户可跳过引导，之后从双语、AI 概览、纪要或运行管理进入。

本地入口说明如何填写已运行的 OpenAI 兼容服务地址和模型名称，例如由用户管理的 LM Studio。云端入口说明如何填写地址、模型名称和凭据。各功能只列出符合其现有约束的配置，实时翻译沿用本地模型限制。

## 用户流程与异常

- 用户选择本地或云端，填写配置并测试连接。测试使用健康检查或合成文本。配置保存后可返回原功能继续操作。
- 用户未配置、服务离线、模型未加载、地址错误、凭据无效或模型不支持时，显示对应状态，并提供编辑或重试入口。
- 云端连接成功与发送会议资料分别处理。功能准备发往云端时，沿用现有确认流程并说明发送范围。模型不可用时保留原文、录音和已有成果。
- 应用内只管理连接配置与功能选择，模型安装、加载和更新由用户在其 LLM 工具中完成。会议备份和诊断中的凭据边界沿用现有规则，迁移验收需核对敏感字段。

## 验收标准

| ID | 操作 | 通过条件 |
| --- | --- | --- |
| LL-01 | 跳过 LLM 配置，安装 ASR 模型并录音 | 录音、转写、回听和原文导出可用，AI 功能入口给出配置引导 |
| LL-02 | 配置真实本地模型并通过连接测试 | 原功能可继续，双语、概览或纪要按各自配置生成 |
| LL-03 | 配置云端模型，拒绝发送会议资料 | 测试阶段未使用会议资料，拒绝后功能不发送会议内容，原始资料仍可查看 |
| LL-04 | 停止本地模型服务或提供无效凭据 | 能区分连接、认证与模型错误，重新配置后可重试 |
| LL-05 | 同一场录音在工作台切换翻译模型 | 轻岛同步，同段同模型复用译文，切回已有模型可命中缓存 |

现有翻译和轻岛回归入口为 `PYTHONPATH=. .venv/bin/pytest -q tests/test_chinese_record.py tests/test_companion.py`。配置错误用隔离模拟接口覆盖，公开发行前补本地和云端连接实测。
