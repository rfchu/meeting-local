# 纪要生成与采用工作流验收（2026-10-23）

## 交互约定

- 主入口按模板、详略、用途配置，点击按钮才生成。默认 AI 整理全文。
- 高级方法：复用当前分析（缺失则分析后自动成稿）、从当前显示纪要派生。规则编排不做语义压缩，详略与用途选择禁用；精简需使用 AI 整理。
- “同时生成分析”为独立队列任务，服务端排队，失败不撤回已保存的纪要。已有当前分析不重复生成。
- 首稿成为工作稿；之后生成的稿件独立保存，显式采用才影响会议成果、跟进、核对状态与检索。采用不表示已完成发送审核，也不发送任何资料。
- 历史稿可另存分支；编辑采用稿后采用指针跟随保存版本。比较、预览、导出前等待自动保存完成，导出绑定具体产物 ID，引用使用该产物的原文版本。
- AI 派生以当前稿为内容范围，保留全部决策/行动/待确认事项与负责人、期限、状态；未引用人工补充不交模型重写，原样附回。原文用于核对依据，无法机械验证模型是否完全忠于语义，仍需人工核对。
- 摘要与核心讨论使用独立字段。新稿保存语义模板快照；旧稿不迁移或覆盖，派生时转换旧 AI 字段语义。

## 2026-10-24：差异核对与草稿引导

- 版本对比增加“只看差异”、基本信息变化数及左右变化条目数。对标题、参会人、目的、地点、记录人及正文分栏核对；高亮采用文字与执行字段的精确比较，不推断语义等价或事实正确性。
- 相同文字的负责人、期限、状态、原文引用变化会显示变化原因；条目及引用顺序调整不计为增删，重复条目的减少仍可识别。旧 AI 稿先按旧字段语义归一化，不因新栏目结构产生虚假差异。
- 对比底部采用按钮保持可见；原文未保存、产物已过期或版本不匹配时不能采用。
- 顶部增加有效草稿待核对引导，排除已采用、过期、旧原文版本和已有后续修订稿的候选；版本菜单显示人工修订、AI 全文、AI 派生、规则成稿、模板和详略。
- 历史任务配置损坏时不再因直接 JSON 解析而导致纪要页崩溃。
- 后端 219 项、前端 43 项通过；TypeScript、Vite 生产构建、Prettier 和 diff 检查通过。隔离合成页面验收了生成草稿后提醒、差异筛选/高亮/变化原因、采用后提醒消失和采用指针更新。此轮只更新前端静态资源，不重启录音与模型服务。
