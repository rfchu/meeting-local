# 内置中文检索与长文字稿验收

## 固定模型与离线运行

内置候选为 BAAI 的 `bge-small-zh-v1.5`，使用 Xenova 提供的 ONNX INT8 转换，512 维、CLS 池化及 L2 归一化。上游原模型采用 MIT 许可证；模型文件不提交进代码仓库。原模型、转换包和各运行库的许可独立适用，分发离线模型时应一并保留上游许可与来源说明。

- 原模型及查询指令：[BAAI 模型卡](https://huggingface.co/BAAI/bge-small-zh-v1.5)
- 固定转换版本：[Xenova 75c43b069aac4d136ba6bc1122f995fedcfd2781](https://huggingface.co/Xenova/bge-small-zh-v1.5/tree/75c43b069aac4d136ba6bc1122f995fedcfd2781)
- 文件大小与 SHA-256、窗口和聚合规则见 `app/local_embedding.py` 的 MANIFEST。

安装分为暂存、校验、发布；失败的下载不替换已安装目录，重试支持 Range 续传，服务端不支持 Range 时从头下载该文件。安装互斥覆盖同进程和不同进程。取消可能等待当前网络读取超时后生效。导入只复制白名单文件，不直接解压 ZIP 路径，拒绝缺文件、额外文件、重复文件、错误版本、大小或哈希不符。模型加载时再次检查哈希，拒绝损坏文件。权重为 ONNX，不执行模型仓库 Python 代码。

推理只使用本地文件与 ONNX CPU，关闭 ONNX 运行时遥测；未安装时不触发隐式下载，不访问外部 Embedding 服务。每个输入按 tokenizer 的 token ID 分窗，不丢弃尾部；归一化窗口向量等权平均后再归一化。该聚合是首版策略，检索单元仍保留原有正文与来源，不等于逐 token 精确定位。外部本机服务的截断策略由其服务端负责。

## 自动测试

`PYTHONPATH=. .venv/bin/pytest -q`。`tests/test_local_embedding.py` 覆盖离线包校验、损坏包保留旧安装、续传与从头重试、失败／取消、进程间互斥、超长输入尾部保留、单位向量、空闲释放、加载失败不留下半初始化状态，以及内置配置／建索引／语义检索／规则变更失效。已有检索、引用问答和录音测试继续运行。

`npm --prefix frontend run test:stream`、`run build`、`run format:check` 验证既有前端行为、类型和构建；可编辑虚拟列表由下述真实页面验收补充。

## 模型实测与质量边界

`PYTHONPATH=. .venv/bin/python scripts/evaluate_embedding.py` 使用 8 条合成资料与 8 个预设问题，包含交付变化、负责人、回款、故障、预算、迁移和未明确期限。INT8 的平均 Recall@3 和 MRR 均为 1.0；使用校验一致的 FP32 参考权重运行 `--fp32-reference /path/to/model.onnx` 时，两项也均为 1.0。已验证真实下载、真实离线包导入、真实 ONNX 推理及完整 SQLite-vec 检索。

这些数值只用于小样本接线检查，不能代表真实会议准确率，也不能证明量化没有质量损失。尚需按真实项目名、人名、同义表达、跨会议冲突及资料无答案构建人工标注评测集；不自动读取用户会议作为评测集。语义相近不等于资料支持结论，沿用问答的引用校验及人工核对。

## 可编辑虚拟列表验收

`PYTHONPATH=. .venv/bin/python scripts/recording_ui_fixture.py --long-demo 10000`，可选 `1000`、`3000`，使用临时数据库和合成音频，不录制麦克风。合成长文字稿时间轴仅用于 UI 测试，配套静音 WAV 为 12 秒，不能用它验证长音频回放准确性。

2026-10-20 本机页面验收：

| 规模 | 验收时片段 DOM 数（随行高变化） | 检查 |
|---|---:|---|
| 1000 段 | 9 | 全量显示切换至 1000 段，再恢复虚拟化；全文搜索末尾 |
| 3000 段 | 9 | 修改后滚动，编辑框保持挂载与焦点；自动保存后刷新恢复 |
| 10000 段 | 9 | 未渲染末尾搜索、Tab 导航、引用定位高亮；定位时约 15 段 |

另验证了 900×900 与 1280×900 窗口切换：同一长句的文字框随可用宽度自动重新增高／缩短，内容高度与可视高度一致，没有隐藏尾部文字。

10000 段资料生成 1319 条检索单元，已用真实内置模型完成索引；语义搜索将包含目标项目的末尾资料排在首条，点击后定位到其来源范围开头。筛选时修改文字即使不再匹配检索词，也会保留正在编辑的片段，移开焦点后重新按条件过滤。

这些验证证明 DOM 数量受控与主要交互可用，未给出滚动帧率或输入延迟保证。待补充更多窗口尺寸、浏览器和输入法组合输入的人工回归。版本对比界面仍为按需打开后的普通列表，后续可按实际瓶颈单独优化。
