# E8：真实设备验收与本机发行边界

当前主方案仍是 M4 Max 本机原生运行。宿主、Python 环境、模型与数据分别管理；本机开发签名应用不是公证的独立安装包。管理入口为“运行管理 → 运行环境 → 本机交付与设备验收”。

## 记录原则

观察只采样状态、计数和时间，不启动／停止录音或模型。达到目标时长不自动判定成功。新增验收结论必须绑定观察开始时及核对时一致的运行环境指纹（后端源码、采集器源码／实际二进制、系统与架构）、报告指纹和人工回听确认。缺少环境记录的历史观察保留，但不能补写指纹来冒充当前版本验收。

六个场景逐项记录；新失败不会被旧通过掩盖。源码、二进制或报告变化后旧结论失效。结论是用户对所述场景的人工核对，不是自动硬件认证或完整语义质量证明。某个模型／音源组合通过也不代表其他组合通过。

## 受控现场矩阵

| 场景 | 操作与最低证据 | 人工回听重点 |
| --- | --- | --- |
| 原生录音短测 | 工作台选定音源并开始，观察至少 60 秒、连续采样及文件增长 | 系统测试语音完整；若测试麦克风，人需实际说话 |
| 三小时连续录音 | 观察 10800 秒，采样充分且无长时间观察缺口，原音增长 | 开始、中间、结束和已标记范围；计时及文件大小不能代替完整性核对 |
| 睡眠唤醒后恢复 | 在允许中断的测试环境手动睡眠／唤醒，返回后按“睡眠唤醒返回”标记，保留前后证据 | 唤醒后是否恢复预期声音、停顿是否明确；不能保证睡眠期间继续采集 |
| 其他音频软件切换 | 手动打开／退出目标软件，在操作后及时标记，需前后文件增长 | 操作前后音轨及后续声音；应用切换／设备计数不是麦克风被抢占的证明 |
| 识别恢复后新文字确认 | 保留识别异常及后续确认覆盖增长的样本，按原配置恢复 | 新语音、新确认文字、重复／遗漏和历史缺段；任务 running 不等于已恢复出字 |
| 明确停止与音轨保留 | 观察持续到工作台明确停录，需正常停止证据和已保存音轨 | 结束前声音是否保存、最后音节是否截断；停止观察不等于停止录音 |

顺序：先确认无正式会议在录制；准备可回听的测试语音；开始录音后从观察入口选择本次会话；按现场操作及时标记；通过工作台停止录音；回听并在原观察记录的“回听与设备验收核对”逐项保存结论。自动到时结束的观察未必包含正常停录，停录场景须另行观察到停止。不要为了验收退出其他人的会议或未经安排强制睡眠。

首次建议系统音频与麦克风分别说清测试编号和时间点。ASR 单独记录所选引擎及配置，人工核对时确认组合范围；当前产品不自动归因第三方软件抢占，也不据一次短测关闭相关 P0 问题。

## 命令行短测（显式开启真实设备）

优先使用工作台。需要隔离短测时，以下命令会真实采集声音，音频保存在新目录；须先安排好测试语音和现场环境：

```sh
.venv/bin/python scripts/hardware_smoke.py --run-real-device --output /private/tmp/tingji-device-smoke-001 --seconds 60 --microphone
```

不传 `--run-real-device` 时拒绝运行；不传 `--microphone` 时仅采集系统音频。要求已授予相关权限、正式写入者空闲和新隔离目录，60～300 秒后正常请求停止。工具不请求新授权、不启动 ASR／LLM、不停止正式服务，不覆盖现有输出；停止未确认时保留现场，不能把未知状态当作停录成功。观察和 WAV 回听文件均保存在本机，含实际声音，勿作为源代码或公共验收附件提交。

## 发行检查

```sh
.venv/bin/python scripts/release_readiness.py
```

只读核对已安装宿主和采集器身份、严格签名、arm64、宿主清单格式／协议／数据库范围、干净构建、源码匹配和 Python 路径存在。检查范围是内置默认连接，不代表用户已保存的其他连接或所有模型依赖均可用；外部服务连接另由现有主动测试确认。不会下载模型、打开设备、改授权、启动或停止服务。

独立发行持续列为未完成：可复现的独立运行环境、Developer ID 发行签名与公证、干净机器安装／升级／回退、完整设备场景证据。当前未申请证书、未作公证、未构建宣称可独立安装的包；不会把 adhoc 签名或已有短测当作发行完成。

## 2026-11-07 本轮实际短测

经用户明确配合，在隔离目录使用已安装 build 4 采集器进行约 60.5 秒系统／麦克风双轨真实采集；60.23 秒观察共 13 次采样，两音轨持续增长，正常停止后确认音轨保留。32 秒处记录用户报告的其他音频软件切换，之后文件继续增长；没有观察到缓冲丢弃、设备切换或采集失败阶段。存在少量时间轴补空，保留为观察事实，不推断其语义影响。

用户回听确认系统音轨正常；麦克风当时无人讲话，因此未验证麦克风语音完整性。未启动 ASR／LLM；未验证三小时、睡眠／唤醒、真实 ASR 恢复，也未复现麦克风抢占。音轨和报告保存在忽略目录 `backups/E8-validation/real-short/`，不入 Git、不导入正式会议库。

该短测在本轮验收指纹功能接入前启动，作为独立实录证据保留，不回填环境指纹，不自动转为新版设备验收通过。下一次正式现场验收应使用更新后的工作台观察入口，并逐项回听。合成 UI 记录与实录分开；合成数据测试的“通过／未通过”不写入正式设备验收清单。
