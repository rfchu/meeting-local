# 使用指南

## 会前和会中

在录音工作台填写会议目标、议程和需要确认的问题。系列会议可从资料库关联最近一次会议，查看未完成事项。按需要选择浏览器麦克风、原生系统音频或原生双音轨，并先试录确认音源。

会中可以标记时间点、记录重点、问题和待办。实时文字用于辅助记录，采集、落盘和识别各有独立状态。遇到采集异常时先检查已保存的音轨，再从「录音恢复」处理可恢复内容。

## 原文与纪要语言

录音方案的「实时识别」可选择原文语言，支持自动识别、中文和英文。新录音默认自动识别。导入音频后的「转写设置」也提供同一选项。开始后本次实时会话保持原有配置，换一种语言重新转写时会生成新的文字稿版本。

在「会后产物」或纪要生成设置中独立选择中文或英文输出。英文原音可以整理为中文纪要，中文原音也可以整理为英文纪要。语言选项随会议准备保存，录音方案记住上次选择。每个已提交的纪要任务保留提交时的输出语言。

旧会议、录音和任务缺少语言配置时沿用中文。规则纪要保留已有分析文字，从当前版本派生保留原语言；需要翻译整理时选择 AI 整理全文。源文引用保留原文。中文内置向量模型的英文检索质量仍待后续专项验证。

## 会后整理

录音结束后可以仅保存，也可以选择快速完成或精细转写。快速完成会复用可用的实时识别结果，再补未覆盖的片段。可从文字稿时间戳回听，校对发言人、姓名和数字。

在会后工作区对照原文处理简记、待办和引用。新生成的纪要可与当前采用稿比较。同模板的普通纪要支持将选中的差异另存为草稿。检查负责人、截止日期和原文依据后，再采用并保存交付版本。交付版本保留当时确认的内容，可导出 Word、PDF 或 Markdown。

线上面试可选择专用纪要模板，整理问答、经历和待核实事项。面试评语与最终决定由用户填写。

## 模型、搜索与运行管理

「运行管理」提供本机模型配置、任务、依赖及诊断入口。使用本地 OpenAI 兼容模型时，先在 LM Studio 等模型工具中启动本机服务，再在听记配置回环地址和模型名称。云端模型使用 HTTPS。

跨会议问答可先查看检索到的证据，再让模型依据所选来源整理。语义检索可在「搜索与引用问答」中安装本地向量模型。模型和会议数据的路径、备份及迁移见[本机维护指南](engineering/WORKSPACE.md)。
