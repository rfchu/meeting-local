# 线上面试纪要首版验收

时间：2026-11-03。范围为第一批模板、准备、结构化生成、人工核对与导出；未实现多轮候选人管理、简历解析或自动招聘评判。

## 自动检查

`tests/test_interview.py`：

- 面试准备随会议保存；私人备注不进入生成上下文。
- 使用专用 JSON Schema，摘录必须是所引用片段中的连续原文，别名恢复为真实片段 ID；无效引用不得发布。
- 默认待核对／忽略的 AI 关注点不导出，保留后导出；人工评价来自独立字段。
- 重新生成保留已核对关注点和评价，旧采用稿保持不变；来源变化后评价待复核，复核前阻止交付。
- 普通会议分析、派生或润色不代替结构化面试，防止混入或改写人工评价。
- 面试原文、简记和纪要不进入通用跨会议检索；Word/PDF/Markdown 沿用既有版式和版本导出。

`frontend/tests/interview.test.mjs`：人工保留状态、原文归属、准备信息标识，以及待复核评价的导出排除。

## 隔离页面

运行 `PYTHONPATH=. .venv/bin/python scripts/recording_ui_fixture.py --interview-demo --port 8766`。

已验证：合成线上面试 → 会议成果 → 选择线上面试纪要 → AI 整理全文 → 查看结构化问答与关注点 → 保留关注点、填写人工评价 → 查看连续摘录 → 自动保存 → 刷新恢复核对结果。使用临时数据库、静音合成音轨和固定模型返回，不录音、不调用真实模型。

## 实际使用边界

原文摘录校验只能验证引用存在，不能证明推理充分、候选人自述真实或问题归属正确；仍需面试官核对。能力栏目描述证据覆盖，不是候选人能力评级。尚未用真实普通话面试评估问答归属、岗位维度覆盖及追问质量。
