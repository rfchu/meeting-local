## D01 验证记录

在 Apple M4 Max、macOS 27.0.1 上完成。样包约 922 MiB，模型权重另行复制到隔离目录。构建使用本机 Python 3.13、FFmpeg 7.1 及现有两个 Python 依赖环境。构建器扫描了 388 个原生文件，递归带入 95 个外部动态库副本。Python 使用框架中的实际解释器，FFmpeg 的传递依赖重写为包内相对路径。

| 验证 | 结果 |
| --- | --- |
| 搬移与环境隔离 | 样包搬到仓库外带空格的新路径；从独立工作目录、空 HOME、无继承环境和无 Homebrew PATH 启动 |
| Python 与后端 | 包内 Python 启动 Uvicorn，回环临时端口的 `GET /api/runtime/host` 返回 200 且 PID 与测试进程一致 |
| FFmpeg | 将 2.148 秒合成语音转换为 16 kHz 单声道 PCM WAV |
| MLX GPU 推理 | Qwen3-ASR-1.7B-8bit 在 M4 Max GPU 上耗时 4.306 秒，输出与预期句子一致。短测使用草稿模式 |
| 动态库来源 | FFmpeg、后台和 MLX 的 dyld 日志分别核对 690、600、603 个唯一加载路径，加载来源均为样包或 macOS 系统目录 |

复跑命令。输出路径必须是仓库外的新目录，测试模型和合成音频应准备在独立目录。

```sh
.venv/bin/python scripts/build_portable_runtime.py "$probe" \
  --python-home /opt/homebrew/opt/python@3.13/Frameworks/Python.framework/Versions/3.13 \
  --ffmpeg /opt/homebrew/bin/ffmpeg
mv "$probe" "$relocated_probe"
cd "$fixture"
env -i HOME="$fixture/home" PATH=/usr/bin:/bin \
  "$relocated_probe/python" backend "$relocated_probe/code/scripts/verify_portable_runtime.py" \
  --bundle "$relocated_probe" --audio "$fixture/smoke.aiff" \
  --model "$fixture/models/qwen3-asr-1.7b-8bit" \
  --aligner "$fixture/models/qwen3-aligner-0.6b-8bit" \
  --expect 'The meeting will start on Friday morning.'
```

本次完成的是运行时重定位样包验证。干净设备、最低 macOS 15、完整 UI 和采集仍需分别实测。样包使用本机开发依赖和临时签名，正式封装需固定依赖来源、缩减包体并核对许可。样包使用的 FFmpeg 构建带有 `--enable-gpl`，发行版的构建选型与再分发条件在 D13 前关闭。
