# 听记独立发行首页评审

[打开低保真原型](standalone-home-wireframe.html) · [D03 验收](standalone-release-tasks.md#d03-p0-验收)

## 当前 App 走查

| 状态 | 观察与边界 | 原型调整 |
| --- | --- | --- |
| 首次使用 | 实机看到宿主先显示连接状态，再通过「打开内嵌工作区」进入。已进入的工作台提供样例会议。未清空正式工作区，首次无模型为设计推演 | 后台验证通过即进入工作台。录音和导入在首屏，模型提示放在操作下方 |
| 日常使用 | 实机看到侧栏会议列表和导入入口，内容区另有导入和开始会议入口。近期记录在侧栏，用户先经过宿主窗口 | 首页突出开始录音与导入。近期会议按状态提供继续整理或查看成果 |
| 有录音或待恢复 | 实机观察到首页提醒通往运行管理，恢复页存在仅保存信息、没有已知音频的记录。现有轻岛支持按录音 ID 返回本场。活跃会话直达是设计推演，本轮未开启采集 | 已核实的活跃会话优先恢复原页面。可处理的中断录音只占一条提醒，空记录留在运行管理 |

## 评审决策

- 首次和日常共用工作台布局。首次状态由资料库与模型可用性决定。后台启动异常时保留可操作的失败状态，成功连接后直接进入工作台。
- 有唯一可确认、可在当前宿主恢复的活跃会话时，打开原会话并保持录音或暂停状态。若会话由其他页面持有，明确提示返回原窗口或使用现有受控接管。会话归属不明确时提供核对入口。
- 无活跃会话时，只为确有可处理的已保存录音或简记显示首页恢复提醒。只有简记时写明「查看已保存简记」。空记录仍可在运行管理中检查。待恢复提示不替用户启动采集。
- 模型提示以能力缺失为条件，允许录音、保存与回听。LLM 引导随对应功能出现。首页优先展示用户动作，详细环境信息进入运行管理。

原型使用示例内容。评审重点为入口顺序、提示层级与会话返回条件。发布视觉样式与实现留到评审后。
